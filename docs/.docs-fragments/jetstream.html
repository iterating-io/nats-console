스트림과 메시지

계정별 JetStream 작업과 메시지 확인 방법을 설명합니다.

스트림과 컨슈머 작업은 먼저 대상 계정을 선택한 뒤 수행합니다. API는 accountPublicKey로 계정을 찾고 JetStream 사용 여부를 확인합니다. 따라서 같은 스트림 이름이라도 다른 계정의 리소스와 혼동하지 않도록 현재 선택한 계정을 확인하세요.

  1. 계정 화면에서 해당 계정의 JetStream을 활성화합니다.
  2. 스트림 화면에서 계정을 선택하고 스트림 이름과 subject를 입력해 생성합니다.
  3. 생성된 스트림의 설정·상태·메시지를 확인하고 필요하면 컨슈머를 추가합니다.
  4. 메시지 화면에서는 계정과 스트림을 명시적으로 선택한 뒤 마지막 메시지를 확인합니다.

스트림 생성 시 subject를 생략하면 서버는 스트림 이름 뒤에 .>를 붙인 기본 패턴을 사용합니다. 스트림 상세 응답에는 이름과 subject 외에 설정, 상태, 클러스터 정보, 생성 시각이 포함됩니다. 스트림과 컨슈머의 변경 및 삭제 작업은 선택한 계정에 적용됩니다.

다른 계정의 스트림을 source로 가져오려면 원본 계정이 source 공유를 허용하고 대상 계정에 필요한 접근 권한이 있어야 합니다. 콘솔은 source 추가 과정에서 계정 사이의 권한을 설정합니다. 스트림에는 여러 source를 등록할 수 있으며, 컨슈머가 있어도 source 추가·수정·삭제를 요청할 수 있습니다. AsyncAPI 문서의 x-source 선언을 검사할 때는 원본과 대상의 연결 상태도 확인합니다.

메시지 읽기는 계정의 stream-reader 사용자 연결을 사용합니다. 이 사용자는 Stream Info 및 Message Get 요청과 응답 inbox를 허용하며 스트림 수정과 삭제 권한은 갖지 않습니다.
