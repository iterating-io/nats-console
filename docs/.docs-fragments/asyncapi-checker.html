AsyncAPI 검사 계정

검사 계정과 선택적 Stream Info import의 역할을 설명합니다.

AsyncAPI 화면은 별도의 asyncapi-checker 계정을 준비하고 각 서비스 계정의 JetStream Stream Info 조회 권한을 선택적으로 연결합니다. 검사 계정은 서비스 계정의 이벤트를 구독하거나 스트림과 컨슈머를 변경하는 용도가 아닙니다.

  1. AsyncAPI 화면에서 검사 계정 준비를 실행합니다. 이미 계정이 있으면 사용자와 상태 조회 접근을 확인합니다.
  2. 검사할 JetStream 사용 서비스 계정마다 Stream Info import를 활성화합니다.
  3. 서비스별 AsyncAPI 선언을 수정한 뒤 asyncapi/check-channels.py로 실제 채널과 source 연결을 검사합니다.

import는 서비스 계정의 $JS.API.STREAM.INFO.> 요청을 검사 계정의 별칭으로 노출하며 activation token으로 보호됩니다. 검사 사용자는 허용된 별칭과 상태 조회 subject에 요청을 발행하고 _INBOX.>로 응답을 받습니다. 검사 대상 계정의 import를 끄면 해당 조회 경로를 제거합니다.

검사 도구는 문서의 x-jetstream.stream과 실제 스트림 subject를 비교하며 스트림을 만들거나 변경하지 않습니다. NATS_ACCOUNT를 지정하면 한 계정에 범위를 좁히고, 그 계정을 source로 참조하는 downstream 연결도 확인합니다. 자세한 판정 기준과 계정 경계는 기존 asyncapi/CHECKER.md에 있습니다.
