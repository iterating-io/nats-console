서비스 개요

NATS Console로 관리할 수 있는 대상과 기본 사용 흐름을 설명합니다.

NATS Console은 기존 NATS Operator 환경의 계정, 사용자, JetStream 리소스를 웹에서 관리하는 콘솔입니다. 운영자는 계정과 사용자 권한을 설정하고, 스트림과 컨슈머 상태를 확인하며, 테스트 메시지를 발행할 수 있습니다.

주요 화면과 목적
화면할 수 있는 일
계정Operator에 속한 계정과 사용자를 확인하고 권한 및 자격 증명을 관리합니다.
스트림계정을 선택해 JetStream 스트림, source, 컨슈머를 관리합니다.
메시지선택한 계정과 스트림의 메시지를 확인합니다.
AsyncAPI별도 검사 계정을 준비하고 서비스 계정의 Stream Info 접근을 선택합니다.

Operator는 NATS 인증의 최상위 신원이고 계정은 메시지와 JetStream 리소스의 경계입니다. 사용자는 계정에 속한 NATS 자격 증명입니다. 콘솔 로그인 계정은 NATS 사용자와 별개이며, 현재 로그인 API는 설정된 관리자 ID와 암호로 admin 토큰을 발급합니다.
